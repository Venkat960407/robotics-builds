# Robotics Builds

Small projects I made for robotics startups, each one built around a company's own product or open-source code.

| Project | What it does |
|---|---|
| [revise-laptop-grader](revise-laptop-grader) | Checks a laptop's battery wear, disk health, RAM, and CPU, and gives it a resale grade from A to D. Windows, macOS, and Linux. |
| [almond-axol-workspace](almond-axol-workspace) | Maps where the Almond Axol's two arms can both reach, and at which table heights, from the robot's URDF. |
| [innate-odom-check](innate-odom-check) | An Innate OS skill that drives a square and measures how much MARS's wheel odometry drifts against the lidar map. |
| [morphoai-homepage-draft](morphoai-homepage-draft) | An unofficial one-page homepage draft for MorphoAI, written from their public YC launch post. |

I'm Venkat, a high school robotics programmer in Redmond, WA. I write the autonomous code (C++, PID, odometry) for my VEX team. I build these with Claude, and each README explains how the project works.
